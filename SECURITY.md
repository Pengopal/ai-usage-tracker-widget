# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](../../security/advisories/new) for
this repository. Don't open a public issue. We aim to acknowledge reports within five working days.

Include what you found, the steps to reproduce it, and the impact you expect. We'll keep you updated while we fix
it and credit you in the advisory unless you'd rather stay anonymous.

Things we especially want to hear about:

- Anything that could expose a user's Claude, ChatGPT or Grok session, or send it anywhere other than that
  provider.
- Ways for a web page to reach the widget's privileged IPC bridge.
- Tampering with the update channel.

## Supported versions

Only the latest release receives security fixes. Installed copies update themselves from GitHub Releases.
